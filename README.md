# ANTI-GRAVITY AI: INFINITE GAME STUDIO ENGINE (CONSOLIDATED MASTER PROMPT)

> **종합 게임 개발 대기업 (The Agency 270명 에이전트 시스템)**  
> RPG, 액션, 로그라이크, 퍼즐, FPS, 시뮬레이션 등 다양한 장르의 고퀄리티 게임을 무한으로 신규 개발·출시하고 지속 패치·유지보수(Auto Live-Ops)하는 차세대 게임 스튜디오 시뮬레이션 플랫폼입니다.

---

## 🚀 빠른 시작 가이드 (Quick Start)

바탕화면의 `AI_COMPANY` 폴더 내 다음 파일 중 원하는 방식을 더블 클릭하여 실행할 수 있습니다.

| 실행 파일 | 설명 | 권장 환경 |
| :--- | :--- | :--- |
| **`run.bat`** (권장) | Python 로컬 API 서버와 2D 웹 대시보드를 동시에 자동 실행합니다. (이원화 시각 및 실시간 동기화) | Windows 일반 환경 |
| **`run_gui.bat`** | 추가 프로그램 설치 없이 웹 브라우저 단독으로 2D 시각화 시뮬레이션을 실행합니다. | 파이썬 미설치 환경 |
| **`run_daemon.bat`** | UI 없이 저전력 CPU 백그라운드에서 태스크 큐 및 틱을 구동하는 헤드리스 데몬 모드입니다. | 저전력/서버 환경 |

## 🏢 시스템 아키텍처 및 구현 명세 (모듈 1 ~ 모듈 5 완료)

> 전체 시스템 상세 인수인계 문서는 루트의 [`HANDOFF.md`](./HANDOFF.md)를 참조하십시오.

### 1. 모듈 1 완료 명세 (Core Foundation)
1. **가상 오피스 이원화 시각 시스템**: 상단 인게임 타임스케일(빠른 시간)과 하단 로그 콘솔 컴퓨터 실제 시각(System Clock `HH:mm:ss`) 완벽 동기화.
2. **백그라운드 엔진 실시간 스트림**: 부서별 실시간 활동 및 가드레일 이벤트 스트림 출력 수리.
3. **명령 콘솔 및 빠른 액션 버튼**: 엔터 전송, 전송 버튼, 6대 핫키 반응 및 비서실장 음성/텍스트 연동.

### 2. 모듈 2 완료 명세 (Infinite Background Generator & 1st HITL Approval UI)
1. **무한 비동기 백그라운드 생성 엔진**:
   - Headless 데몬 및 서버 백그라운드에서 전담 병렬 워커 스레드(`_background_generator_worker`)가 가동.
   - 270명 에이전트 지연 로딩 풀(시장조사팀, 기획1팀, QA팀 전문 인력)을 동적으로 매핑하여 다양한 장르의 게임 기획안을 지속 적재.
   - STEP 04(1차 대표 기획 승인)에 도달하여 메인 시뮬레이션 파이프라인이 PAUSE 상태에 진입하더라도 엔진이 멈추지 않고 결재 대기 큐에 안건을 적재하며 병렬 스레드로 후속 기획을 계속 생산.
2. **1차 기획 승인 상세 요약 보고서 결재함 UI**:
   - 3단 탭 구성: `승인 대기(N)`, `QA 반려/폐기(N)`, `처리 완료(N)` 실시간 뱃지 카운트 및 양방향 동기화.
   - 6가지 핵심 요소를 집대성한 비주얼 기획 보고서(`modal-gdd`) 제공.

### 3. 모듈 3 완료 명세 (Source Code Pipeline & 2nd HITL Code Review)
1. **5대 소스 코드 및 에셋 번들 생성**:
   - `game_core.js`, `GameManager.cs`, `main.py`, `GDD_Detailed.md`, `assets_manifest.json` 자동 생성.
2. **2차 대표 코드 검토 창 (Code Review Inspector)**:
   - 코드 미리보기, 메트릭, AI 리팩토링 콘솔("쿨타임 줄여줘", "전투 로직 수정"), 사규 제4조 원본 보존 롤백.

### 4. 모듈 4 완료 명세 (GitHub 1 Game = 1 Repo & Auto Live-Ops)
1. **로컬 5대 폴더 정돈 저장 (`output/`)**:
   - `output/{YYYY-MM-DD}_{Genre}_{GameTitle}/` 경로에 1_GDD, 2_Assets, 3_SourceCode, 4_Build, 5_Marketing 자동 저장.
2. **.env 기반 GitHub 1 Game = 1 Repo 자동 연동**:
   - .env 파일 자동 체크, GitHub REST API 단독 저장소 생성 및 초기 커밋/푸시 (토큰 미설정 시 AWAIT_INTEGRATION 안심 처리).
3. **지속 라이브 유지보수 (Auto Live-Ops)**:
   - STEP 11 라이브 유지보수팀: `CHANGELOG.md` 생성 및 `v1.0.1` 릴리즈 태그 자동화.

### 5. 모듈 5 완료 명세 (Playable WebGL, AI Playtest, Steam Storefront, Portfolio)
1. **인브라우저 즉시 실행 플레이어**:
   - `4_Build/index.html` 인터랙티브 WebGL/HTML5 런너 & 대표 전용 디버그 오버레이(무적, 쿨타임 제거, 배속, 보스 소환).
   - 실시간 인게임 이벤트 스튜디오 터미널 역전송 (`POST /api/telemetry`).
2. **270인 에이전트 자율 AI 플레이테스트**:
   - 100회 헤드리스 가상 플레이테스트, 클리어율, 평균 생존 시간, 45개 좌표 데스 히트맵, 밸런스 권고안 산출.
3. **스팀 상점 페이지 스튜디오**:
   - SVG 캡슐 그래픽(Header, Main, Hero) 및 4개 국어(KO/EN/JP/ZH) 로컬라이제이션 패키징.
4. **전사 게임 포트폴리오 경영 대시보드 & 무한 스프린트 순환**:
   - STEP 12 출시작 누적 관리(다운로드, 가상 매출, 스팀 평점) 및 차기작 자동 무한 순환 스프린트.
     ⑤ 아트 & 사운드 방향성 (Visual & Audio Direction)
     ⑥ QA 종합 검수 의견 & 사규 7대 가드레일 러버 스탬프 인장 (VERIFIED PASS / QA REJECTED)
   - 대표 [승인] 클릭 시 프로젝트가 다음 파이프라인(STEP 05 레벨 & 시나리오 상세화 -> 모듈 3 소스코드/에셋 생성)으로 전이.

### 3. 모듈 3 완료 명세 (Source Code Pipeline & 2nd HITL Code Review Inspector)
1. **소스 코드 및 완제품 에셋 생성 파이프라인**:
   - 1차 기획 승인이 완료된 게임에 대하여 270명 에이전트 중 4대 전문 부서(내러티브, 아트, 사운드, 프로그래밍)가 연동되어 완성도 높은 메인 소스 코드 및 에셋 번들을 자동 생성.
   - 5대 핵심 산출물: WebGL 엔진(`game_core.js`), Unity C# 통합 매니저(`GameManager.cs`), Python 물리 시뮬레이터(`main.py`), 상세 기획서(`GDD_Detailed.md`), 2D/3D 스프라이트 및 SFX 매니페스트(`assets_manifest.json`).
2. **2차 대표 코드 검토 (HITL Code Review) & AI 리팩토링 콘솔 UI**:
   - STEP 09 도달 시 엔진이 자동 PAUSE되며, 상단바 및 팝업으로 `modal-code-review` 코드 검토 창(Code Review Inspector) 출력.
   - 5대 파일 탭 뷰어 및 줄 번호/코드 미리보기(Preview) 지원.
   - 자연어 대표 명령 콘솔("이 부분 쿨타임 줄여줘", "전투 로직 수정해줘", "패링 판정 늘려줘" 등) 바인딩 -> AI 프로그래머가 코드를 즉각 실시간 리팩토링 반영.
   - 사규 §7 제4조 '원본 보존 원칙'에 입각한 1-클릭 코드 롤백(Rollback) 및 리팩토링 이력 타임라인 관리.
   - 대표가 `[🚀 최종 승인 및 푸시]` 버튼을 누를 때만 STEP 10(모듈 4 스토어 준비 및 패키징)으로 전이.

### 2. 12단계 무한 게임 개발 파이프라인
1. `STEP 01` (07:00) **시장조사**: 글로벌 게임 시장 트렌드, 스팀 인기 장르 분석 및 전원 출근
2. `STEP 02` (08:30) **기획 1팀**: 신작 게임 10개 콘셉트 도출, 코어 게임플레이 루프 및 세계관/IP 기획안 작성
3. `STEP 03` (10:00) **게임 QA팀**: 게임 QA팀 10건 전수 검사 (사규 위반 3건 반려 / 통과 7건 중 상위 TOP 3 선정)
4. `STEP 04` (11:30) **★ 1차 대표 기획 승인 ★ (HITL INTERRUPT 1)**: 상세 게임 기획 요약서(6대 핵심 요소) 결재 대기 -> 엔진 PAUSE
5. `STEP 05` (13:00) **기획 2팀**: 레벨 디자인, 퀘스트/시나리오 상세화, 적 배치 및 기믹 테이블 작성
6. `STEP 06` (14:30) **게임 아트팀**: 캐릭터/배경 스프라이트, 콘셉트 원화, HUD/UI 디자인 및 시각 에셋 패키징
7. `STEP 07` (15:30) **게임 사운드팀**: 메인 테마 BGM 작곡, 타격감 SFX 제작, 환경음 사운드 믹싱
8. `STEP 08` (16:30) **게임 프로그래밍팀**: 게임플레이 루프 프로그래밍, 물리 엔진 결합, WebGL 경량화 빌드 소스 코드 완성
9. `STEP 09` (17:30) **★ 2차 대표 코드 검토 ★ (HITL INTERRUPT 2)**: 소스 코드 검토 창 출력, 대표 AI 리팩토링 지시 및 최종 푸시 승인 대기 -> 엔진 PAUSE
10. `STEP 10` (18:00) **사업·퍼블리싱팀**: output/ 디렉터리에 5대 폴더 규격 안전 저장 및 스토어 론칭 에셋 패키징
11. `STEP 11` (18:30) **라이브 유지보수팀**: 백그라운드 버그 수집, 핫픽스 생성, CHANGELOG.md 작성 및 GitHub v1.0.1 릴리즈 태깅 자동화
12. `STEP 12` (19:00) **비서실 브리핑**: 비서실장(김세리) 5줄 전사 요약 브리핑 제출 및 차기 스프린트 대기

### 3. The Agency 270명 에이전트 지연 로딩 (Lazy Loading)
- 토큰 낭비 및 메모리 과부하를 방지하기 위해 50x50 오피스 맵에는 12개 부서 팀장 및 핵심 실무진(32명)이 실시간 물리/A* 이동을 수행합니다.
- 상단 `👥 270명 조직도` 클릭 시 REST API(`/api/roster`)를 통해 12개 부서 270명 전체 에이전트 명단을 지연 로딩(Lazy Loading)하여 검색 및 필터링할 수 있습니다.

### 4. 사규 7대 절대 규칙 (Guardrails)
1. 메일/외부 스토어/서버 실제 자동 배포 절대 금지 (초안 및 검토본까지만 생성)
2. SNS 계정 및 스팀 상점 페이지 실제 자동 게시 금지 (대표 최종 결정 필수)
3. 결제, 구독, 과금 API 자동 실행 금지 (증빙 검증 후 대표 승인)
4. 원본 파일 삭제 및 덮어쓰기 금지 (output/ 복제본 분기 저장 원칙)
5. 외부 미연동 상태를 '완료'로 거짓 보고 금지 (`AWAIT_INTEGRATION` 라벤더 명시)
6. 확인 안 된 정보 및 라이선스 미검증 에셋 사용 금지 ('미확인' 처리)
7. 2단계 HITL 승인 파이프라인(1차 기획 승인 / 2차 소스코드 검토) 임의 스킵 금지

### 5. 산출물 저장 규격
`output/{YYYY-MM-DD}_{Genre}_{GameTitle}/`
- `1_GDD/`: 게임 기획 요약서 (6대 핵심 요소 리포트) 및 QA 검수 보고서
- `2_Assets/`: 프롬프트 명세, 스프라이트/원화/BGM 목록
- `3_SourceCode/`: 코어 엔진 스크립트 (`game_core.js` 등)
- `4_Build/`: WebGL/Canvas 실행 가능한 경량 빌드 (`index.html`)
- `5_Marketing/`: 스토어 설명서 (`store_description.md`) 및 릴리즈 노트

```
AI_COMPANY/
├── index.html           # Google Stitch SaaS UI, 2D Canvas 오피스, 이원화 시각 대시보드

├── server.py            # 로컬 REST API 웹서버 (듀얼 런타임 브리지)
├── run.bat              # 통합 원클릭 실행 배치 파일
├── run_gui.bat          # 독립형 브라우저 UI 실행 배치 파일
├── run_daemon.bat       # 저전력 백그라운드 데몬 실행 배치 파일
├── requirements.txt     # 환경 설정 명세서
├── .env.example         # GitHub PAT 및 보안 템플릿
├── test_module2.py      # 모듈 2 (백그라운드 기획 & 1차 HITL 결재) 검증 테스트
├── test_module3.py      # 모듈 3 (소스코드 생성 & 2차 HITL 리팩토링) 검증 테스트
├── test_module4.py      # 모듈 4 & 5 (GitHub 연동, 플레이테스트, 스팀 상점, 포트폴리오) 검증 테스트
├── HANDOFF.md           # [전사 종합 인수인계서] 모듈 1~5 통합 개발 명세
├── output/              # 게임 프로젝트별 5대 폴더 안전 저장소
└── logs/                # 전사 이벤트 로그 저장소
```
